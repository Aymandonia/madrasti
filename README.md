# نشر منصة مدرستي

يحتوي هذا المجلد على واجهة للرفع إلى GitHub Pages وخادم Node.js لـ Render. ينشئ الخادم الجداول اللازمة عند أول تشغيل ويحفظ بيانات المدارس في PostgreSQL على Neon.

1. **GitHub.** أنشئ مستودعاً بفرع `main` وارفع محتويات حزمة النشر مع الحفاظ على مجلدَي `.github` و`scripts`. اختر **Settings → Pages → Source → GitHub Actions**. [دليل GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
2. **Neon.** أنشئ مشروعاً وانسخ رابط الاتصال من **Connect**. ضع الرابط في متغير `DATABASE_URL` في Render فقط. [دليل Neon](https://neon.com/docs/connect/connect-from-any-app)
3. **Render.** اختر **New → Blueprint** واربط مستودع GitHub. يستخدم Render ملف `render.yaml` ويولّد `APP_SECRET`. أدخل `DATABASE_URL`، وفي `FRONTEND_ORIGIN` أدخل أصل موقع Pages، مثل `https://your-user.github.io` دون اسم المستودع. بعد النشر افتح `https://اسم-الخدمة.onrender.com/health` وتأكد أن الاستجابة هي `{"ok":true}`. [دليل Render Blueprints](https://render.com/docs/infrastructure-as-code)
4. **ربط الواجهة بالخادم.** في GitHub افتح **Settings → Secrets and variables → Actions → Variables** وأنشئ متغير مستودع باسم `MADRASTI_API_URL` بقيمة رابط خدمة Render. شغّل إجراء **GitHub Pages** من تبويب **Actions → Run workflow**. سيرفع الإجراء ملفات الواجهة العامة فقط.

## استخدام المنصة

- يختار المدير **إنشاء حساب** ويدخل اسمه الثلاثي واسم المدرسة ورمزاً من ٨ أرقام. يدخل مباشرة ويظهر معرّف مدرسته في نافذة الحساب.
- من **المدرسون → إنشاء حساب مدرس**، يختار المدير اسم المدرس ورمزه من ٨ أرقام. إذا أضاف رقم الهاتف ظهر **مشاركة عبر واتساب** بعد الحفظ. يفتح الزر رسالة جاهزة، ويرسلها المدير من واتساب. يمكن مشاركة الرمز عند إنشاء الحساب أو تغييره، لأن الخادم يحتفظ ببصمة الرمز.
- يسجل المدرس الدخول بمعرّف المدرسة واسمه ورمزه. يضيف المدير الفصول والمواد ثم يسندها إلى المدرس. يستطيع المدرس إدخال سجلات الطلاب والحضور والدرجات في الفصول المسندة إليه.
- يحتفظ التبويب بجلسة الدخول في الذاكرة، وتحتاج إلى إعادة الدخول عند إعادة تحميل الصفحة.
- تظهر الإعلانات للمدرسين، وتظهر التقارير التي يرسلها المدرسون في **إشعارات المدرسين** عند المدير. تستطلع الصفحة المفتوحة الخادم كل ١٠ ثوانٍ. تنبيه المنصة يعمل أثناء فتح الموقع. إذا عُدّل السجل من جهاز آخر أثناء حفظك، يظهر طلب تحديث حتى لا يطغى أحد التعديلين على الآخر.
- يُنزَّل PDF مباشرة. يبقى استيراد أسماء الطلاب من ملفات Excel متاحاً.
- تبدأ المدارس الجديدة بسجلات فارغة. تبقى بيانات النسخة القديمة في المتصفح الذي استُخدمت عليه. يمكن إعادة إدخال الأسماء أو استيرادها في المدرسة المطلوبة.

## اختبار محلي

استخدم Node.js 24 وشغّل `npm ci --ignore-scripts` ثم `npm test`. يعمل الاختبار باستخدام PostgreSQL محلي مضمّن، من دون حساب Neon. لتشغيل الواجهة والخادم محلياً مع قاعدة PostgreSQL، انسخ `.env.example` إلى `.env` واملأ متغيراته ثم شغّل `npm start` وافتح `http://localhost:3000`.
